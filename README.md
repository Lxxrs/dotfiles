# dotfiles

My personal macOS configuration files, deployed with [GNU Stow](https://www.gnu.org/software/stow/).

Each top-level directory is a Stow package that mirrors the layout of `$HOME`,
so packages can be installed individually.

## What's in here

| Package    | Tool                                         | Notes                                                              |
| ---------- | -------------------------------------------- | ------------------------------------------------------------------ |
| `fish/`    | [fish](https://fishshell.com)                | Two-line prompt, frozen theme, completions                         |
| `ghostty/` | [Ghostty](https://ghostty.org)               | JetBrainsMono Nerd Font, Catppuccin Latte / Macchiato (auto-switch)|
| `nvim/`    | [Neovim](https://neovim.io) 0.12+            | `vim.pack` for plugins, `vim.lsp` for language servers             |
| `starship` | [Starship](https://starship.rs/)             | Custom Shell Prompt                                                |

```sh
dotfiles/
├── fish/.config/fish/
├── ghostty/.config/ghostty/
└── nvim/.config/nvim/
```

## Requirements

Core:

```sh
brew install fastfetch fish fzf git neovim starship stow
brew install --cask font-jetbrains-mono-nerd-font ghostty
```

Language servers enabled in `nvim/.config/nvim/init.lua` (install only the ones you need):

| Server                  | Language       | Install                                    |
| ----------------------- | -------------- | ------------------------------------------ |
| `ansible`               | Ansible        | `brew install ansible-language-server`     |
| `astro`                 | Astro          | `npm i -g @astrojs/language-server`        |
| `bashls`                | Bash           | `brew install bash-language-server`        |
| `docker_language_server`| Docker         | `brew install docker-language-server`      |
| `fish_lsp`              | fish           | `brew install fish-lsp`                    |
| `gopls`                 | Go             | `brew install gopls`                       |
| `jinja_lsp`             | jinja2         | `cargo install jinja-lsp`                  |
| `lua_ls`                | Lua            | `brew install lua-language-server`         |
| `ruff`                  | Python (lint)  | `uv tool install ruff`                     |
| `tailwindcss`           | Tailwind       | `brew install tailwindcss-language-server` |
| `tinymist`              | Typst          | `brew install tinymist`                    |
| `ty`                    | Python (types) | `uv tool install ty`                       |

Optional: **mole** (macOS cleanup/maintenance CLI) — the fish completions in
`fish/.config/fish/completions/` are for its `mole` / `mo` commands and are
harmless if it isn't installed.

Neovim plugins (fzf-lua, mini.completion, quicker.nvim, gitsigns.nvim,
nvim-lspconfig) are installed automatically by `vim.pack` on first start and
pinned in `nvim/.config/nvim/nvim-pack-lock.json`.

## Installation

```sh
git clone https://codeberg.org/Lxrs/dotfiles.git ~/dotfiles
cd ~/dotfiles
stow -vt "$HOME" fish ghostty nvim
```

Install a single package by naming just that one, e.g. `stow -vt "$HOME" --no-folding nvim`.

Dry-run any command first with `-n`:

```sh
stow -nvt "$HOME" fish
```

Other useful invocations:

```sh
# re-link after adding, moving or removing files
stow -Rvt "$HOME" fish ghostty nvim

# remove a package's symlinks
stow -Dvt "$HOME" ghostty
```

## Adding a new config

```sh
mkdir -p ~/dotfiles/<tool>/.config
mv ~/.config/<tool> ~/dotfiles/<tool>/.config/<tool>
cd ~/dotfiles && stow -t "$HOME" <tool>
git add <tool> && git commit
```

## Notes

### fish

— `config.fish` runs `fastfetch` on every interactive session.

— `fish_variables` is tracked and contains fish's universal variables, including `fish_user_paths` with machine-specific absolute paths: (Homebrew bin/sbin, a pinned Node version, `~/.local/bin`).

— On a new machine, check `echo $fish_user_paths` after stowing and adjust the file if any of those paths don't apply.

— `conf.d/fish_frozen_theme.fish` is also generated by fish (`fish_config`) - edit it through the web config, not by hand.

— Completions in `completions/mo.fish` source `mole.fish` via `(status dirname)` rather than a hardcoded path, so they work regardless of where the repo is checked out.

### Ghostty

— On macOS, Ghostty reads both `~/.config/ghostty/` and `~/Library/Application Support/com.mitchellh.ghostty/`, with the latter taking precedence. If a config still exists there, remove it so the stowed one applies.

### Neovim

— Requires 0.12 or newer for `vim.pack` and the `lsp/` directory convention.

— Update plugins with `:lua vim.pack.update()` and commit the resulting lockfile changes. Leader key is `<Space>`; `<A-h/j/k/l>` move between windows in normal, insert and terminal mode.
